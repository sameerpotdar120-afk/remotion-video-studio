# Samulation Shorts: complete production skill

Everything needed to make every Samulation YouTube Short in the house style: the locked mascot, the 3D/2D engine, the set library,
the YouTube agent skills (yt-script, yt-package, yt-seo, retention, comments, audit, plan, viral), the creator's voice profile,
sound, parallel rendering, QA, thumbnail and SEO kit, plus the reference video worked example and the 95-100% quality path.

**Start here:** `SKILL.md`, then the `reference/` file for each step.

## Install
- **Google Antigravity:** copy this folder to `<your workspace>/.agent/skills/samulation-shorts/`, and copy `workflows/*.md` to
  `<your workspace>/.agent/workflows/`. Then type `/new-short` (or ask "make a new Samulation short about …").
  (If your Antigravity version uses a different skills path, check its docs for the location; the folder works as-is.)
- **Claude Code:** copy to `~/.claude/skills/samulation-shorts/`.
- **First run on any machine:** `bash tools/setup.sh` until it prints "All set."
