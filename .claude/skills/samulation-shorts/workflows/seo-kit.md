Follow reference/10-seo-thumbnail-upload.md.
1. Write 10 titles, score with youtube/yt-package/title.py, keep the top 2-3; check the thumbnail pairing with --thumb.
2. Render a clean frame (QS='&nocap') of the payoff moment, run tools/thumbnail.py with <= 3 words, check the 180x320 feed version.
3. Description (lines 1-2 answer the search query), 10-15 tags, hashtags, query test, upload time in ET + IST, pinned comment, sources.
4. Save as Samulation-NN-SEO-Kit.md, send it with the thumbnail. End with "Ship it, or change it?".
