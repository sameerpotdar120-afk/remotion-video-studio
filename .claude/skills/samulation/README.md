# samulation (Claude skill)

The complete production system for the Samulation channel: reference analysis at 30 fps, the measured rule book, the
story-script formula, the locked mascot, physics-correct mechanisms synced to the voice-over, and two engines
(three.js in Remotion, and Blender EEVEE). Start with `SKILL.md`.

Install: copy this folder to `~/.claude/skills/samulation/` (or keep it in a repo's `.claude/skills/`).
Requirements: ffmpeg, Python 3 (numpy, Pillow, faster-whisper), Node + Playwright Chromium, Blender 4.5 LTS (for engine B).

Everything here is our own code and notes. Reference videos are private study material and are not included.
The tutorial method summary credits the MIT-licensed `claude-animated-shorts` project (Mr omi).
