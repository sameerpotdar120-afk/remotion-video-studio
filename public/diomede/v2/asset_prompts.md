# Diomede Islands v2: GPT Asset Prompts (all new)

Every image for this video is new. Nothing is reused from the Darién, North Sentinel or Diomede v1 packs.
Script: `script_hindi.txt`. Beat plan: `reference_breakdown.md`.

Not made by GPT (on purpose, for accuracy):
- **Maps and coastlines:** real satellite imagery (NASA, EOX Sentinel-2) and real outlines (Natural Earth, OpenStreetMap).
- **Flags, Hindi text, numbers, arrows, the laser beam, the date line, the iris wipe, the split screen, labels and chips:** drawn in code so they're always correct and razor sharp.
- **The village close-up:** a real U.S. Coast Guard aerial photo of Diomede village (2008, public domain), which beats any generated image.

---

## 0. How to generate

- One asset per message. Paste the **Style Lock** once at the start of a new ChatGPT chat, then send the prompts one by one.
- Sizes: **1024×1536** portrait for full-screen images, **1024×1024** for objects and icons, **1536×1024** for wide textures.
- `PNG-T` = a real transparent background. If you get a checkerboard or white background, reply: *"Regenerate with a truly transparent alpha background, not a drawn checkerboard."* If it still fails, use remove.bg or Photoroom.
- Make 2–3 versions of each and keep the best. Zoom to 100% and check edges, hands, faces and anything that should be symmetrical.
- **Make each matching set in one chat, one after the other:** the pins (C1–C3), the soldiers (D1–D2), the hiker poses (F3–F4), the sticker (G1).
- Name files exactly as listed and send them all together.
