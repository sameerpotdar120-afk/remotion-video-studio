Everything here is an original illustration. Nothing is based on the reference video's cartoon characters or any
existing show. The maps (Delhi airport, the globe, Nauru from above) come from code: EOX Sentinel-2 cloudless
(CC BY 4.0, credited on screen) and Natural Earth (India's official boundary), so they need no prompts. Icons,
stamps, counters, the passport (marked प्रतीकात्मक) and the route lines are drawn in code too.

Paste the style line at the start of every prompt so the set matches. All vertical 9:16. Where it says CUT-OUT,
also make a version on a plain flat mid-grey background, full figure, nothing cropped, so we can lift it onto the
map. Every image gets an "AI illustration" label on screen.
