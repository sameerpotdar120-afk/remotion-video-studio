# Hiroshima short: image prompts for ChatGPT

**How to use:**

1. Open **one** ChatGPT chat and make the **character sheet first** (section 1). Keep using that same chat so the characters stay consistent.
2. Copy each prompt block below exactly as written. Each one already contains the full style and character description.
3. Download each image as **PNG** and rename it to the file name shown above its prompt.
4. If an image comes back with a white or grey background instead of a transparent one, just send it anyway; I can cut it out.
5. Zip the images in their folders (`chars/`, `props/`, `bg/`) and send them in parts, as you did before.

There are **58 images** in total. I build these parts in code: the stopwatch numbers, captions, sun glare, lens flares, motion blur, the white flash and the pencil-hatch shadows.

**Also needed:** the **audio** of the reference short. The video you sent has no sound track.
