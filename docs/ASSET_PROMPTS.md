## 0. Read this first — how to get true 4K out of ChatGPT

| Item | Rule |
|---|---|
| **Generator sizes** | ChatGPT's image tool currently outputs **1536×1024** (landscape), **1024×1536** (portrait) or **1024×1024** — not 4K. If your version offers a larger size, use the largest; the upscale steps below still apply. |
| **Upscale to 4K** | Use **Upscayl** (free, open source, Real-ESRGAN) → model *"Ultrasharp"* for illustrations, *"Real-ESRGAN"* for photo plates. Scale ×4. |
| **Characters / props** | Generate **1024×1024**, transparent background → upscale ×2 → **2048×2048 PNG**. |
| **Backgrounds** | Generate **1536×1024** → upscale ×4 (6144×4096) → crop the centre to **3840×2160**. Prompts below keep everything important inside the middle band so the 16:9 crop never cuts it. |
| **Transparency** | Always add *"transparent background, PNG"*. If ChatGPT gives a white background, ask: *"same image, background fully transparent"*. Last resort: remove.bg / Photoshop *Remove Background*. |
| **Consistency** | Generate the **Style Reference Sheet (1.2) first**. Then for EVERY character/prop, attach that sheet and start the prompt with *"Use the attached image as the strict style reference."* |
| **Folders** | `public/assets/chars`, `props`, `docs`, `icons`, `bg`, `textures`, `sfx`, `music` (already created in the repo). |
| **Never AI-generate** | Maps, flags, real historical documents and artworks. Maps come from real data (section 10), flags are drawn in code (`src/lib/fx/flags.tsx`), and real artworks are public-domain scans (section 9). |

> Why faces are blank: the code draws eyes, brows and mouths on top (`Face.tsx`) so every character
> can blink, talk (lip-flap), glare and react on any frame at 60 fps. A painted face would be frozen.
> Arms are tucked in for the same reason: the code draws rubber-hose arms and hands.

## 1. Global style lock

### 1.1 STYLE A — chibi cut-out characters & props (paste at the start of every character/prop prompt)

```
STYLE A: 2D vector cartoon illustration for an animated history YouTube channel. Chibi proportions:
very large perfectly round head (about 40% of total height), small rounded bell-shaped body, tiny
feet just visible at the bottom. Flat colours with soft cel shading (one shadow tone, one subtle
highlight), clean thick dark-brown outline (#2A211B) of even width on every shape. Warm peach skin
(#F6D9BF). Historically accurate 1760s–1770s clothing rendered with crisp detail: brass buttons,
cravats, waistcoats, tricorne hats with edging, buckled shoes. Muted, earthy, slightly desaturated
palette, no neon. Gentle paper-grain texture inside the fills. Character stands upright, front view
turned very slightly (10°) to the right, centred, feet touching the bottom edge of the canvas, full
body visible with 6% empty margin left/right/top. BLANK FACE: the face is completely smooth skin with
NO eyes, NO eyebrows, NO nose, NO mouth, NO cheeks blush — leave it empty. ARMS HIDDEN: both arms are
tucked inside the coat, no hands visible. Transparent background, PNG, no ground shadow, no text,
no border, square 1024×1024.
```

### 1.2 Style Reference Sheet — generate FIRST, reuse for everything

File: `public/assets/chars/_style_reference_sheet.png` (not used in video)

```
STYLE A (see above). A character model sheet on a plain light-grey background showing FIVE chibi
characters standing in a row at the same scale: a colonial townsman in a brown coat and black
tricorne; a British redcoat soldier of 1770 with musket strap; a gentleman with a white powdered
wig; a woman in a 1770s blue gown with white cap; a child of 4. All faces completely blank (no eyes,
no mouth, no brows, no nose), arms hidden in clothing. Show the exact outline thickness, the cel
shading and the paper grain. 1536×1024.
```

### 1.3 STYLE C — 3D-rendered hero props (the reference's crown, stamp block, eraser, cap are 3D renders)

```
STYLE C: Stylised 3D render of a single object, like a high-end animated feature film prop:
soft rounded forms, slightly exaggerated toy-like proportions, physically based materials (real wood
grain, brushed brass, gold with soft reflections, worn leather), soft three-point studio lighting
(warm key from top-left, cool rim light from the right), gentle ambient occlusion in the creases,
subtle contact shadow is NOT included. Object centred, 3/4 view from slightly above, filling 80% of
the frame. Transparent background, PNG, 1024×1024. No text unless specified, no people.
```

Use STYLE C for: `crown_gold.png`, `stamp_handle_wood.png`, `eraser_red_blue.png`, `tea_chest.png`,
`molasses_barrel.png`, `quill_inkwell.png`, `lantern_pair.png`, `cannon_small.png`.
Everything else in section 4 stays STYLE A (flat cel-shaded) — mixing the two is exactly what the reference does.

### 1.4 Matching the reference's figure style — checklist for every character

- Head ≈ 40% of height, perfectly round; body a soft bell/egg shape; feet tiny or hidden.
- One flat colour per clothing piece + ONE soft shadow tone on the side away from the light (light from top-left).
- Outline: even dark-brown, roughly 1/100 of the character height (thicker than typical clipart).
- Details sit ON the silhouette: buttons, lapels, cravat, hat lace — no tiny noisy textures.
- No gradients across the face, no blush, no nose — the code adds dot eyes, thin brows and a simple mouth.
- When a character is placed on a photographic plate, the code adds a contact shadow and slight depth-of-field —
  do NOT paint a ground shadow into the PNG.

## 10. Maps — accurate, copyright-free, aligned

### 10.1 Vector data (already in the repo, public domain)

- `public/maps/colonies-1775.json` — 13 colonies from US Census Bureau boundaries (via `us-atlas` 3.0.1). Maine is merged into Massachusetts and West Virginia into Virginia, as they were in 1775. Vermont is a separate "disputed" shape (claimed by both NY and NH). Western land claims are deliberately left out.
- `public/maps/land-50m.geo.json`, `countries-50m.geo.json` — Natural Earth 1:50m (via `world-atlas` 2.0.2). **Coastlines only.** Never present modern country borders as 1760s borders.
- Rebuild: `node scripts/build_colonies.mjs <us-atlas>/states-10m.json <world-atlas> public/maps`

### 10.2 Satellite style (NASA Blue Marble — public domain)

1. Download **Blue Marble Next Generation, "world.topo.bathy" tile B1** (covers 90°W–0°, 0°–90°N, 21 600 × 21 600 px = **240 px per degree**) from NASA Visible Earth.
2. Crop only what you need (decoding a full tile wastes memory). Pixel = (lon − (−90)) × 240, row = (90 − lat) × 240.
   East-coast crop (lon −86…−64, lat 28…48):
   ```bash
   # ImageMagick: width = 22°×240 = 5280, height = 20°×240 = 4800, x = (−86+90)×240 = 960, y = (90−48)×240 = 10080
   magick world.topo.bathy.200412.3x21600x21600.B1.jpg -crop 5280x4800+960+10080 +repage -quality 92 public/assets/bg/bm_eastcoast.jpg
   ```
3. In code, register it with its bounds — alignment is exact because the code uses the same 240 px/degree plate carrée:
   ```ts
   rasters={[{ src: staticFile('assets/bg/bm_eastcoast.jpg'), west: -86, south: 28, east: -64, north: 48 }]}
   ```
4. Make one crop per region you zoom into (Atlantic overview, Massachusetts close-up, Europe, Britain).

### 10.3 Terrain / mountain ranges (Appalachians, 3D look)

- **Natural Earth "Shaded Relief" 1:10m** (`SR_HR`, public domain, 21 600 × 10 800 = 60 px/degree): good for wide shots.
- For close-ups make your own hillshade from **SRTM 90 m** or **GEBCO** elevation (both free):
  ```bash
  gdalwarp -t_srs EPSG:4326 -te -86 33 -72 45 -tr 0.0041666667 0.0041666667 srtm_tiles.vrt appalachians_dem.tif   # 240 px/degree, plate carrée
  gdaldem hillshade -z 2.5 -az 315 -alt 40 appalachians_dem.tif hillshade_appalachians.tif
  gdal_translate -of JPEG -co QUALITY=92 hillshade_appalachians.tif public/assets/textures/hillshade_appalachians.jpg
  ```
  Register with `west:-86, south:33, east:-72, north:45`, use `style: { mixBlendMode: 'multiply', opacity: 0.45 }` on top of the parchment land, and give the camera key a `tilt: 28` for the 3D mountain look.

### 10.4 Alignment check (do this once per raster)

Render a still with `MapPin`s at Boston, New York, Philadelphia and Cape Cod's tip at max zoom; every pin must sit exactly on the coastline in the raster. If not, the crop offsets are wrong.

### 10.5 The 1763 Proclamation Line

`PROCLAMATION_LINE` in `src/lib/map/data.ts` is an **approximate** trace along the Appalachian watershed. Before publishing, overlay `pd_proclamation_1763_map.jpg` (section 9) and nudge the points to match.

## 12. QA checklist before animating

- [ ] Every file name matches this doc exactly (case-sensitive).
- [ ] Characters: 2048×2048, transparent, faces blank, arms hidden, feet on the bottom edge.
- [ ] Backgrounds: 3840×2160 after crop, no people, no letters.
- [ ] Documents: zoom in and check spelling of every heading.
- [ ] Redcoats at the Massacre: yellow facings. Washington 1754: young, no wig. Jefferson: red hair. Monticello: no dome.
- [ ] No feathered "Indian" costumes for the Tea Party, and no caricatures of enslaved people or Crispus Attucks.
